# v0.3.1-preview: Workplace Compatibility

**Target:** Whiskerwood 0.7.209.0 on Windows. **Available on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3814077514)** and as a GitHub download. Workshop publication was confirmed by the author on 7 October 2026. **In-game validation is pending**; this remains a preview release.

## What Changed

- Skip unsupported warehouse workplaces while preserving their existing workers.
- Avoid the specific rejected hire that could stop an assignment run at these workplaces.
- Keep one-click assignment, feasible minimum crews before best-fit extra staffing, and the saved construction reserve.

The affected native `ResourceBuilding` family includes `GranaryResourceBuilding`, used by prefab `tinywarehouse`. Its assignment API returns no mutable workforce in the inspected game version. The planner now excludes these workplaces and protects their occupants instead of attempting a hire. Those workers are not available for other jobs or the free construction reserve.

## Verification

Targeted workplace regressions, the full automated editor suite, Windows cook and package checks passed for the final v0.3.1-preview package on 7 October 2026. Temporary diagnostic instrumentation is not included. The [native workplace capability record](https://github.com/repte/whiskerwood-worker-optimizer/blob/v0.3.1-preview/docs/verification/2026-10-07-native-workplace-capability.md) contains the source findings and exact build evidence.

These results are not a shipping-game acceptance test. This fix addresses one unsupported workplace path; other assignment failures remain possible. Only observed assignment effects count as confirmed changes.

## Install and Test

Subscribe on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3814077514) and restart the game after Steam downloads the update.

For manual installation, download [WorkerOptimizer-v0.3.1-preview.zip](https://github.com/repte/whiskerwood-worker-optimizer/releases/download/v0.3.1-preview/WorkerOptimizer-v0.3.1-preview.zip), not a source-code archive. Close the game and extract the included `WorkerOptimizer` folder into:

```text
%LOCALAPPDATA%\Whiskerwood\Saved\mods\
```

The mod folder contains `WorkerOptimizer.pak` and `WorkerOptimizer.uplugin`. Use either a local installation or Workshop, never both.

Use a separate test save. Run assignment at night or just after a new day starts; running it during the day may cause assignment errors. Confirm existing occupants of affected warehouse workplaces stay unchanged while supported neighboring workplaces can still be staffed, subject to eligibility and reserve constraints. Compare actual workers before and after, not just the icon's busy state.
