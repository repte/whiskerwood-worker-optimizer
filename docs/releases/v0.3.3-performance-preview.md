## Changes

- Faster assignment planning through reduced repeated matrix work, exact solver
  shortcuts, and reuse of equivalent row calculations.
- The existing exact assignment approach is retained. There is no approximate
  search, hybrid replacement solver or arbitrary candidate limit.
- The assignment icon uses the same native gameplay-HUD visibility checks as the
  Campfire Panel mod. It appears only in the visible gameplay HUD and hides in
  menus, with hidden HUD, during loading or saving, and in replay.
- Simulation pause and end of day do not themselves hide the icon. Opening a
  pause menu still hides it. Hiding the icon does not cancel or restart an active
  assignment; the current state returns with gameplay visibility.
- Minimum crews, worker eligibility, protected occupants and the saved builder
  reserve remain binding. The unsupported warehouse protection from
  [v0.3.1-preview](v0.3.1-preview.md) is retained.

## Measured Performance

Six compiled-editor planner benchmarks with **1,000 workers** took
**5.61-14.55 seconds of accumulated planner calls** on the test machine. They
cover unique and tied productive scores, reserves of one and three, equal and
varied builder qualities, and mixed-priority strict/weighted fixtures.
Assignment hashes and checked coverage, staffing, productivity and reserve
objectives were unchanged across the final measurement runs.

These are host-specific planner measurements, **not a promise that an entire
in-game assignment finishes within 15 seconds**. Settlement capture, scoring,
school candidate search, frame scheduling and applying changes are outside this
planner-only measurement. Complex school combinations can still be expensive.
The public manual interface continues to use equal building priorities; mixed
priorities are additional internal regression cases.

See the [large-settlement verification record](../verification/2026-10-08-large-settlements.md)
for measurements, hardware context, regression evidence and remaining limits.

## Install and Test

Use [WorkerOptimizer-v0.3.3-performance-preview.zip](https://github.com/repte/whiskerwood-worker-optimizer/releases/download/v0.3.3-performance-preview/WorkerOptimizer-v0.3.3-performance-preview.zip),
not the source-code ZIP. The existing [Workshop item](https://steamcommunity.com/sharedfiles/filedetails/?id=3814077514)
will be updated separately; its currently published version is v0.3.1-preview.

Close the game before replacing either file in:

```text
%LOCALAPPDATA%\Whiskerwood\Saved\mods\WorkerOptimizer\
  WorkerOptimizer.pak
  WorkerOptimizer.uplugin
```

Use only one installed copy: local or Workshop. Test a separate save, preferably
at night or just after day start. Check actual assignments and protected workers,
the reserve, complete run duration, and icon visibility through pause, end of day,
menus, HUD hiding, loading and saving. Hiding the icon during a request must not
cancel, duplicate or restart that request.
