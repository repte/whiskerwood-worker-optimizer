# Worker Optimizer 0.2.0

**Auto-assign workers to suitable jobs, with one click or on a schedule.**

First regular release for **Whiskerwood 0.7.209.0 on Windows**.

## Highlights

- Responsive settings with General, searchable Priorities and a detailed Logbook.
- Optional assignment at day start or every 5, 10 or 15 real-time minutes. Timers count pauses; due assignments wait until the simulation resumes.
- Minimum operating crews before extra workers, while respecting priorities, worker eligibility and the free-builder reserve.
- A logbook with timestamps, status icons/colors, confirmed changes and grouped reasons for unstaffed buildings.
- All 17 game-language catalogs, following the game's language setting.
- Bounded automatic replanning when relevant conditions change. The start button stays locked while busy; there is no player cancellation.
- Repaired history selection, category expansion, small-window text sizing and clipped settings text.

## Download and Install

Download **WorkerOptimizer-v0.2.0.zip**, not GitHub's source-code archives.
Close the game and extract the `WorkerOptimizer` folder into:

```text
%LOCALAPPDATA%\Whiskerwood\Saved\mods\
```

It must contain `WorkerOptimizer.pak` and `WorkerOptimizer.uplugin`. No Python
or Unreal Editor is needed. Use either a local installation or the Workshop
subscription, not both. The Workshop update is prepared separately for manual
submission; this GitHub release does not update the Workshop item.

## Validation and Limits

Automated tests, native UI checks and package validation passed. The final
in-game test was reported passing on **6 October 2026**. The PAK is identical
to the tested `0.2.0-local.7` candidate; only descriptor version/description
and distribution documentation changed for release.

Keep a backup save. Large-settlement performance, all-language presentation,
long sessions and interactions with other mods still need broader validation.
Insufficient eligible workers can leave buildings unstaffed; the reserve stays
binding. Confirmed assignment changes are not automatically rolled back.

See the [guide](https://github.com/repte/whiskerwood-worker-optimizer/blob/v0.2.0/docs/GUIDE.md)
for controls, implementation and known limits. `SHA256SUMS.txt` verifies the
downloaded archive.
